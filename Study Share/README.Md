# 📚 StudyShare - Buy & Sell Course Notes

A peer-to-peer academic marketplace where university students can buy and sell course notes, assignments, and study materials online.



## ✨ Features

- 📤 **Upload Notes** — Students can upload and sell their study materials
- 🔍 **Browse & Search** — Find notes by course, subject, or university
- 💳 **Purchase System** — Instant access to materials after payment
- 👤 **User Profiles** — Manage your uploaded and purchased notes
- ✅ **Verified Materials** — Professor-approved content tagging

## 🚀 Getting Started

No server setup needed — this is a static frontend project.

```bash
# 1. Clone the repository
git clone https://github.com/ahidnahid/StudyShare.git

# 2. Open in browser
# Simply open index.html in any browser
```

Or use VS Code Live Server for the best experience.
